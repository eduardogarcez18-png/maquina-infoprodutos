## Quando usar esta skill

Antes de criar oferta ou criativos. Sempre que os criativos não estiverem convertendo bem (pode ser problema de avatar).

## Input necessário

- Nicho e sub-nicho
- Descrição do produto
- Concorrentes principais (nomes ou URLs)
- Dados de clientes existentes (se houver): depoimentos, perguntas frequentes, reclamações

## Processo passo a passo

1. Identificar o evento ativador: o que fez o avatar buscar uma solução agora?
2. Mapear a jornada emocional: frustração → esperança → ceticismo → decisão
3. Identificar nível de consciência (Schwartz): inconsciente / consciente do problema / consciente da solução / consciente do produto / mais consciente
4. Levantar as 5 principais dores (dores que tiram o sono, não dores genéricas)
5. Levantar os 3 desejos principais (transformação desejada em palavras do próprio avatar)
6. Levantar as 5 objeções principais (por que não compraria mesmo querendo)
7. Identificar linguagem natural: as palavras exatas que o avatar usa para descrever o problema
8. Mapear onde está online: grupos, canais, influenciadores, formatos consumidos
