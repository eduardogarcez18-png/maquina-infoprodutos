# Meta Andromeda — Princípios para Criação de Criativos

## O que é o Meta Andromeda

Andromeda é a abordagem do Meta para entrega de anúncios em escala: o algoritmo encontra o público a partir do sinal gerado pelo próprio criativo. Isso muda a lógica de campanha — o criativo não é só o conteúdo do anúncio, é o mecanismo de segmentação. Um criativo que fala diretamente com um avatar específico seleciona esse avatar no feed.

Consequência prática: criar um criativo genérico que "serve para todo mundo" é criar um criativo que o algoritmo não consegue calibrar. Especificidade gera sinal. Sinal gera entrega eficiente.

---

## Diversidade Criativa

O Meta precisa de diversidade real para aprender — não de variações cosméticas.

**O que é variação cosmética (evitar):**
- Mesmo roteiro, cor de fundo diferente
- Mesmo hook, fonte diferente
- Mesmo vídeo, legenda diferente

**O que é variação real (fazer):**
- Ângulos diferentes (dor vs. transformação vs. mecanismo)
- Formatos diferentes (UGC vs. editorial vs. estático)
- Avatares diferentes (primário vs. secundário)
- Níveis de consciência diferentes (consciente do problema vs. consciente da solução)
- Hooks diferentes com corpos diferentes

**Regra prática:** se dois criativos foram para o mesmo avatar, com o mesmo ângulo e o mesmo argumento, são cosméticos — não geram aprendizado novo.

---

## Broad Targeting

No Meta Andromeda, o broad (sem interesse, sem restrição de público além de localização e faixa etária) funciona porque o sinal de conversão treina o algoritmo melhor do que qualquer segmentação manual.

**Quando usar broad:**
- Produto com volume de conversões para alimentar o algoritmo (meta: 50 conversões/semana por conjunto)
- Criativos com ângulo específico que já fazem a segmentação pelo conteúdo
- Fase de escala após validar qual ângulo funciona

**Quando usar interesse:**
- Produto novo sem histórico de conversão
- Budget baixo (< R$50/dia) onde o broad pode desperdiçar impressões
- Nicho muito específico onde o interesse reduz o custo por clique qualificado

**Regra prática:** broad tende a ganhar no longo prazo, mas exige volume de dados para funcionar. Com budget limitado, começar com interesse e migrar para broad após as primeiras conversões.

## Variações por Avatar

Cada avatar tem dores, desejos e linguagem diferentes. Um criativo feito para o avatar primário pode não conectar com o secundário — e vice-versa.

**Como criar variações por avatar:**
1. Identificar os 2–3 avatares mais relevantes para o produto
2. Para cada avatar, criar ao menos 1 criativo com a dor específica dele no hook
3. Documentar qual avatar cada criativo mira — para análise posterior
4. Comparar CPAs por avatar para descobrir qual tem maior LTV

**Exemplo:**
- Avatar A (jovem iniciante): "Nunca consegui aprender a desenhar do jeito certo"
- Avatar B (fã adulto): "Quero aprender a desenhar meu personagem favorito depois de anos tentando"
- Avatar C (pai/mãe): "Quero dar um presente diferente para meu filho fã de anime"

Três criativos, três avatares, três sinais diferentes para o algoritmo.

## Variações por Nível de Consciência

O nível de consciência do avatar define o ponto de entrada do criativo. Usar o nível errado é falar para alguém que não está pronto para ouvir aquela mensagem.

| Nível | O que o avatar pensa | Ângulo do criativo | Hook típico |
|---|---|---|---|
| Inconsciente | Não sabe que tem o problema | Não usar em campanha fria — custo alto | — |
| Consciente do problema | Sabe que tem o problema, não sabe a solução | Dor + agitação + solução | "Você também sente que..." |
| Consciente da solução | Sabe que existe solução, não conhece o produto | Mecanismo + diferencial | "Por que outros métodos não funcionam" |
| Consciente do produto | Conhece o produto, não comprou ainda | Oferta + prova + urgência | "Já viu esse produto? Veja o que dizem" |
| Mais consciente | Conhece, considerou, precisa de razão final | Preço + garantia + bônus | Retargeting |

**Regra prática:** a maioria do público frio está entre "consciente do problema" e "consciente da solução". Começar com esses dois níveis e ajustar com base nos dados de CTR e CVR.

## Criativos por Hipótese

Todo criativo deve responder uma pergunta estratégica sobre o avatar ou o mercado. Sem hipótese, o criativo é conteúdo — não teste.

**Estrutura da hipótese:**
> "Se [avatar] sente [situação específica], então um criativo com [ângulo] deve gerar [métrica] acima de [benchmark]."

**Exemplos:**
- "Se o avatar já tentou tutoriais gratuitos sem resultado, então um criativo de contra-narrativa deve ter CTR > 2% em público frio."
- "Se o avatar está no nível consciente do problema, então um criativo de dor deve ter Hook Rate > 35%."
- "Se a objeção principal é preço, então um criativo mostrando o stack de valor deve aumentar CVR da LP em 2pp."

**Regra:** sem hipótese documentada, não há aprendizado com o resultado — só dado sem significado.

## Importância de Ângulos Diferentes

Ângulo é o ponto de entrada emocional do criativo. Dois criativos com o mesmo ângulo competem pelo mesmo sinal e pelo mesmo segmento de público — não ampliam o alcance.

**6 ângulos base:**
1. **Dor** — identificação com o problema. Para avatar consciente do problema.
2. **Transformação** — visão do resultado. Para avatar que acredita ser possível.
3. **Mecanismo** — curiosidade intelectual. Para avatar que já tentou outras soluções.
4. **Prova social** — credibilidade por resultado de semelhante. Para avatar cético.
5. **Curiosidade** — loop aberto, informação que muda o quadro. Para avatar em scroll passivo.
6. **Contra-narrativa** — dissonância cognitiva. Para avatar exposto a muito conteúdo do nicho.

**Regra de produção:** na primeira rodada de testes, cobrir ao menos 3 ângulos diferentes. Identificar qual ângulo gera melhor CTR + CPA. Escalar esse ângulo antes de testar os demais.

---

## Não Criar Variações Cosméticas

Variação cosmética é qualquer mudança que não altera a mensagem central, o ângulo, o avatar ou o ponto de entrada emocional.

**Cosméticas (não geram aprendizado):**
- Mudar cor do botão
- Mudar thumbnail do vídeo
- Mudar fonte do texto sobreposto
- Adicionar emoji no headline
- Mudar ordem de slides do carrossel

**Reais (geram aprendizado):**
- Mudar o hook (pergunta vs. declaração vs. resultado)
- Mudar o ângulo (dor vs. transformação)
- Mudar o formato (vídeo vs. estático)
- Mudar o avatar alvo
- Mudar o nível de consciência abordado

**Regra:** se a mudança não altera a hipótese que está sendo testada, não é um teste — é ruído.

## Formatos de Criativo

| Formato | Quando usar | Força | Custo de produção |
|---|---|---|---|
| **Estático (imagem)** | Teste rápido de ângulo, retargeting, oferta direta | Baixo custo, fácil de testar | Baixo |
| **UGC (depoimento)** | Prova social, avatar cético, produto que precisa de credibilidade | Alta autenticidade | Médio |
| **Carrossel** | Mecanismo passo a passo, múltiplos resultados, comparação | Educativo, gera engajamento | Baixo/médio |
| **Reels / Vídeo curto (< 30s)** | Awareness, hook forte, produto visual | Alto alcance, formato nativo | Médio |
| **VSL curta (2–5 min)** | Produto com mecanismo a explicar, ticket médio | Alta intenção de compra | Alto |
| **Print / Conversa** | Autenticidade, prova social, bastidores | Parecer orgânico | Baixo |
| **Editorial** | Autoridade, nicho educado, produto de método | Credibilidade | Médio |

## Como Avaliar um Criativo Vencedor

Um criativo vencedor não é apenas o que gerou mais vendas na primeira semana. É o que combina:

| Critério | Benchmark | O que indica |
|---|---|---|
| CTR | > 1,5% (feed) | Relevância para o público |
| Hook Rate (3s) | > 30% | O início para o scroll |
| Hold Rate (50%) | > 40% | O meio mantém atenção |
| CPA | < meta definida | Retorno sobre investimento |
| Consistência | Resultado estável por 5+ dias | Não é flutuação |
| Volume | > 50 cliques antes de concluir | Dados suficientes |

**Criativo vencedor = CTR bom + CPA dentro da meta + resultado consistente por pelo menos 5 dias.**

Um criativo com CTR alto mas CPA ruim tem problema na página ou na oferta — não é vencedor. Um criativo com CPA bom mas CTR baixo tem escala limitada — pode funcionar, mas esgota o público rápido.
